# Project Brief: Dubodots

## Overview
Dubodots is a personal dotfiles repository designed to automate the setup of a development environment on macOS (and potentially Linux). It includes configuration files for shell (Zsh, Bash), terminal multiplexers (Tmux), editors (Vim), and installation scripts for system packages and applications via Homebrew.

## Core Goals
- **Automation**: Streamline the setup of a fresh machine with a single entry point.
- **Consistency**: Ensure the same environment across different machines.
- **Portability**: The setup should be self-contained within the git repository, minimizing external dependencies (specifically moving away from cloud sync services like Google Drive for configuration).

## Current Status
Active development to decouple the setup from Google Drive and make it a standalone git-based configuration.
